The game

A treasure is hidden somewhere on a 20 × 20 map (400 cells). Every player digs the same map. One dig costs 0.2 ASE, with up to 5 digs per wallet on each map. A cell can only be dug once, and every answer stays visible to everyone.

🔥 HotThe treasure is within 3 cells (diagonals included)
❄️ ColdThe treasure is further away

The treasure

The treasure grows with every dig on the map, up to the winning dig, plus anything carried over from the previous map. It is sent to the finder's wallet (a Claim button appears right away, and the game sends it automatically within a few minutes otherwise). A new map starts a few minutes later. Digs confirmed just after the treasure was found aren't refunded: they are added to the next map's treasure. Each dig is also one chance in the weekly ASE Airdrop.

Contract and admin powers

Contract: see the explorer (Asentum testnet). Every ticket, draw and payment is public on chain.

What the admin can do: pause digging, change the dig price and the digs per wallet for the next maps, and change the wallets that receive the game fees. The game operator opens each map with a hidden answer sheet whose fingerprint is published on chain before the first dig, so answers cannot be changed afterwards. What the admin cannot do: move, freeze or take players' funds or the treasure.

Asentum testnet: testnet ASE has no monetary value.
